# Random Drops Datapack

This datapack allows all blocks in Minecraft to drop random items when broken. It enhances the gameplay experience by introducing an element of surprise with every block you break.

## Features

- **Random Item Drops**: Each block can drop a variety of items, making resource gathering more exciting.
- **Customizable Loot Tables**: You can easily modify the loot tables to change what items can drop from specific blocks.
- **Efficient Execution**: The datapack is designed to run efficiently with minimal impact on game performance.

## Installation

1. Download the datapack and extract the contents.
2. Place the `random-drops-datapack` folder into the `datapacks` folder of your Minecraft world.
3. Load your world and run the command `/reload` to initialize the datapack.

## Usage

Once installed, the datapack will automatically handle random drops for all blocks. You can customize the loot tables located in `data/randomdrops/loot_tables/blocks/custom_block_loot.json` to define what items can drop from each block.

## Customization

To customize the random drops:

1. Open the `custom_block_loot.json` file.
2. Modify the loot table entries to include the items you want to drop and their respective probabilities.
